# 無印風公寓 3D 擺設

依照實際尺寸平面圖（1/40）建立的 3D 户型，可以在瀏覽器裡自由擺放家具。

**線上版：** https://leonsheep0612.github.io/floorplan-3d/

## 功能

- **3D / 平面 / 人視角 / 漫遊** 四種視角；人視角以視線高度看房間，擋住的牆自動降低；漫遊可用 WASD 或手機方向鍵在屋內走動
- **家具庫** 50 種家具（含 IKEA 布沙發／皮沙發、BOAXEL 壁掛衣櫃、懸空電視櫃、軌道燈、吊燈、人形身高參考），點選後可用「款式」直接替換，點一下或拖曳到畫面上就能新增
- **我的方案**：把擺設存成多套方案（現況、方案 A…），隨時載入、更新、比較
- **操作手冊**：首次進入自動顯示，可縮小到角落再點開
- 拖曳移動家具，自動吸附 5cm 格線與牆面；`R` 旋轉 90°、`Q`/`E` 旋轉 15°
- 可調整每件家具的寬、深、高、離地高度與顏色
- 牆高切換（全高 / 半牆 / 低牆），可疊上原始平面圖對照
- 各空間面積（m² / 坪）自動計算，點空間名稱即可飛到該處
- 復原 / 重做、截圖、匯出 / 匯入 JSON
- **分享連結**：把目前配置編碼進網址，別人打開就能看到同樣的擺設
- 配置自動存在瀏覽器（localStorage）

## 本機執行

純靜態網站，不需建置：

```bash
python -m http.server 8000
```

然後開啟 http://localhost:8000 。Three.js 透過 jsDelivr CDN 載入。

## 結構

| 檔案 | 說明 |
| --- | --- |
| `js/plan.js` | 户型資料：牆、門窗、房間、預設家具（以平面圖像素座標定義，1px ≈ 1.154cm） |
| `js/furniture.js` | 家具模型與目錄 |
| `js/main.js` | 場景、互動、UI |

參考 [wy51ai/floorplan-3d](https://github.com/wy51ai/floorplan-3d) 的做法。尺寸由平面圖換算，僅供參考，實際以現場丈量為準。
